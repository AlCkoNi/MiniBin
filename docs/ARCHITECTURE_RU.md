# Архитектура MiniBin 1.1

## Общая модель

MiniBin — обычное Win32 GUI-приложение без видимого главного окна. Код написан на Go и использует Win32/Shell API напрямую через стандартный пакет `syscall`. Внешних Go-зависимостей нет.

## Модули

`src/main.go` содержит жизненный цикл приложения, системный трей, меню, таймеры, обработку команд и обновление иконки.

`src/win32.go` — минимальный слой привязки к Win32: окно сообщений, меню, Shell_NotifyIcon, SHQueryRecycleBinW, SHEmptyRecycleBinW, ShellExecuteW и MessageBoxW.

`src/config.go` читает и сохраняет `minibin.ini`.

`src/cleanup.go` содержит универсальную очистку временных папок. В нём нет пользовательских абсолютных путей.

`src/version.go` содержит версию и имя автора.

`assets/*.ico` — пять фиксированных состояний иконки.

## Поток сообщений

1. Программа создаёт скрытое окно Win32.
2. Через `Shell_NotifyIconW` добавляется иконка в системный трей.
3. Скрытое окно получает `WM_COMMAND`, `WM_TIMER` и callback-сообщения трея.
4. Раз в 5 секунд `SHQueryRecycleBinW` обновляет состояние `Empty` и текущую иконку.
5. Auto Clean использует отдельный Win32 timer.
6. Очистка выполняется в goroutine, чтобы не блокировать UI message loop.

## Безопасность расширений

Публичная ветка не должна содержать жёстко заданные пути конкретного пользователя. Любой путь для новой функции должен либо вычисляться из стандартных переменных Windows, либо задаваться пользователем через конфигурацию/интерфейс.
