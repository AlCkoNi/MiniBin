# Руководство пользователя MiniBin 1.1

## Назначение

MiniBin — портативная утилита Windows, работающая в системном трее. Она отображает состояние Корзины, открывает её, очищает её вручную или по таймеру и вместе с очисткой удаляет доступное содержимое временных папок.

## Установка

Установка не требуется. Распакуйте весь архив в одну папку и запустите `MiniBin.exe`.

Обязательные файлы рядом с EXE:

```text
MiniBin.exe
minibin.ini
empty.ico
25.ico
50.ico
75.ico
full.ico
```

Если ICO-файл отсутствует, программа использует стандартную системную иконку для соответствующего состояния.

## Меню

`Open` открывает Корзину Windows.

`Empty` очищает Корзину без диалога подтверждения, системного звука и окна прогресса. Пункт становится серым, если Корзина пуста. После вызова `Empty` MiniBin также пытается очистить `%TEMP%` и `%WINDIR%\Temp`.

`Auto Clean` задаёт автоматический запуск той же процедуры очистки:

- `Off` — отключено;
- `30 min` — каждые 30 минут;
- `1 hour` — каждый час;
- `3 hour` — каждые 3 часа.

`My Function` — зарезервированное подменю для дополнительных функций. В публичной версии 1.1 оно намеренно пустое и ничего не выполняет. Оно оставлено как стабильная точка расширения для разработчиков. Подробности: `docs/MY_FUNCTION_RU.md` в исходном пакете.

`About` показывает версию, размер EXE и автора.

`Exit` завершает MiniBin.

## Двойной клик

Двойной клик по иконке в трее выполняет `Empty`, только если Корзина содержит элементы.

## Индикатор заполнения

MiniBin использует пять состояний: `Empty`, `25%`, `50%`, `75%`, `Full`. Состояние выбирается по объёму содержимого Корзины относительно `MaxFillSizeMB` из `minibin.ini`.

## Настройки

```ini
[Configure]
AutoCleanMinutes=0

[Display]
MaxFillSizeMB=1024
```

Допустимые `AutoCleanMinutes`: `0`, `30`, `60`, `180`.

Если `MaxFillSizeMB` отсутствует или некорректен, используется 1024 MB.

## Очистка временных файлов

MiniBin удаляет только то, что операционная система разрешает удалить. Открытые, заблокированные и защищённые файлы могут остаться. Ошибка удаления одного элемента не прерывает общую очистку.

## Удаление MiniBin

Закройте MiniBin через `Exit` и удалите его папку. Приложение не устанавливает службу, драйвер или запись автозапуска.
